#  Expense Tracker

## 📌 About the Project
Expense Tracker is a personal finance management application designed to help users track their daily income and expenses. It allows users to record transactions, monitor spending habits, and manage their budget effectively.

## ✨ Features
- Add and manage daily expenses.
- Track income and expenses.
- View transaction history.
- Categorize expenses.
- Calculate total income and expenditure.
- Monitor remaining balance.
- Simple and user-friendly interface.

##  Project Objective
The main objective of this project is to help users manage their personal finances, understand spending patterns, and develop better financial habits.
